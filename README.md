# 信息链训练场

电子信息工程导论复习训练网站。依据课程课件与学生复习提纲整理，包含 180 道单选、多选、判断训练题，每种 60 道。

支持章节练习、限时模拟考试、答案解析与课件实际页码、错题本、收藏，以及学习记录导入导出。题库属于课程训练题，并非考试原卷。

## 手机与夜间阅读

页面右上角可选择“跟随系统 / 日间模式 / 夜间模式”，浏览器会记住选择。主题切换不改变答案或考试截止时间。界面适配手机窄屏。

## 数据与使用

学习记录保存在当前浏览器，不上传、不同步到其他设备。原本地版与网页版的记录分别保存，换地址或设备可通过导出/导入 JSON 迁移。首次访问网页需要网络，本地下载后可双击 index.html 使用。

模拟考试每题等权，多选必须完整选对，漏选、错选或多选均不得分；空题计错，折算为百分制。正式考试评分以教师说明为准。

## 发布

纯静态网站，GitHub Pages 从 main 分支根目录发布。运行文件采用相对路径，无需构建和后端。这里只包含网站与题库，不包含原始课件或任何个人学习记录。
